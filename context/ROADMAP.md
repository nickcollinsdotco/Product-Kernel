# Roadmap

## Now

* Establish canonical context architecture
* Establish Product Kernel principles
* Define reasoning-to-build workflow
* Define decision capture conventions
* Create initial Product Kernel skill
* Create minimal command set
* Test the system against a real project
* Document failures and contradictions

## Next

* Add orientation workflow
* Add decision-state model
* Add context synchronisation
* Add build handoff
* Add review and validation workflow
* Create worked examples
* Improve onboarding for a fresh repository

## Later

* Public installation flow
* Additional agent integrations
* More sophisticated context schemas
* Automated contradiction detection
* Context linting
* Project health/status tooling
* Optional visualisation of product decisions and relationships

## Explicitly not a priority yet

* Large multi-agent orchestration systems
* Databases
* Vector memory
* Complex dashboards
* Large command libraries
* Automatic product decision-making without clear boundaries

The methodology should be proven before additional infrastructure is added.
