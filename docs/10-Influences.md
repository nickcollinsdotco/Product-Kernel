# Influences

Product Kernel is an independent project informed by existing work in AI-native design and development.

## Layers

Jamie Mill

https://layers.jamiemill.com/

Layers provides the primary inspiration for the product reasoning side of Product Kernel.

Particularly influential ideas include:

- diagnosing problems rather than assuming their level
- reasoning across multiple product layers
- treating the conceptual model as a critical design concern
- using targeted methods rather than a rigid end-to-end checklist
- capturing useful residue from product reasoning

Product Kernel does not attempt to reproduce the Layers implementation.

## Archē

Josh Millgate

https://github.com/joshmillgate/arche

Archē provides the primary inspiration for persistent project context and structured AI-assisted development workflow.

Particularly influential ideas include:

- persistent project context
- project state
- feature context
- technical and developer context
- explicit development workflow
- context synchronisation

Product Kernel does not attempt to reproduce Archē as a fork.

## The synthesis

The central Product Kernel idea is the connection between the two:

```text
product reasoning
       ↓
decisions
       ↓
persistent context
       ↓
autonomous implementation
       ↓
validation
       ↓
updated context
```

Layers helps answer:

> What should we understand and decide?

Archē helps answer:

> How do we persist context and execute systematically?

Product Kernel focuses on the system between those points.

## Attribution principle

References and inspiration should remain visible and explicit.

Product Kernel should add original synthesis, original documentation and original implementation rather than merely repackage existing work.
